# 🧰 GitHub 宝藏应用日报｜第 2 期
**2026 年 10 月 21 日 · 周三**

今天挑了 5 个不同类型的开源应用：**快捷输入、时间管理、视频剪辑、密码安全、影音娱乐**。

其中有两个特别值得学生党尝试：一个能减少每天重复打字的时间，另一个能让你知道自己的时间究竟花在哪里。

本期项目均有公开源码和明确的开源许可。Stars 为 **2026-10-21 查询 GitHub 页面时显示的约数**，并非精确实时计数。

## ① Espanso — 把重复打字变成几个字符

**⭐ 14.7k｜Windows / macOS / Linux｜GPL-3.0**

[GitHub 官方仓库](https://github.com/espanso/espanso)

**它解决什么问题？**

假设你经常需要输入邮箱地址、固定回复、代码模板或者 Markdown 片段，每次重新打字都很麻烦。

Espanso 可以自动将短文本替换成你预先定义的长文本。

例如，你可以配置：

- 输入 `:mail` → 自动替换为你的邮箱地址。
- 输入 `:date` → 自动插入当前日期。
- 输入 `:sig` → 自动插入常用签名。
- 输入 `:latex` → 自动插入常用 LaTeX 模板。

它还支持动态变量、表单和脚本扩展。

**最亮眼的地方：** 不局限于某个编辑器，在大量桌面应用的输入框中都能使用。项目在 2026 年仍有版本更新，包括 Linux Wayland 兼容性改进。

**使用门槛：** 免费。基础配置需要编辑 YAML 文件，稍微有一点学习成本。

**隐私提醒：** 它需要处理键盘输入事件，建议从官方渠道安装，不要随意安装来源不明的扩展，也不要把密码写进明文配置。

**推荐指数：★★★★★**

尤其适合经常写代码、笔记、邮件和实验报告的人。

## ② ActivityWatch — 看看你的时间究竟去哪了

**⭐ 19.3k｜Windows / macOS / Linux｜MPL-2.0**

[GitHub 官方仓库](https://github.com/ActivityWatch/activitywatch)

这是今天我最想推荐的项目。

**它解决什么问题？**

你可能每天在电脑前待了七八个小时，但真正用于学习、娱乐、浏览网页的时间分别有多少？

ActivityWatch 是一个自动记录电脑使用情况的工具。

它可以记录：

- 每个应用使用了多长时间。
- 浏览器中不同网站的使用时间（需安装对应扩展）。
- 电脑活跃和离开的时间。
- 每天、每周的使用趋势。

**最亮眼的地方：** 不需要手动点击开始或结束计时，它会自动收集使用数据，再通过可视化面板展示。

而且它采用本地优先设计，默认不需要把使用记录上传到第三方服务器。近期版本还在改进跨设备同步、中文界面和性能。

**使用门槛：** 免费。安装后即可开始基础记录；浏览器详细记录需要额外安装扩展。

**隐私提醒：** 记录可能包含窗口标题和浏览器访问记录。建议设置敏感信息过滤，避免将数据目录随意共享。

**推荐指数：★★★★★**

适合想改善时间管理，但不喜欢手动填写时间日志的人。

## ③ LosslessCut — 几秒钟剪完一个大视频

**⭐ 44.8k｜Windows / macOS / Linux｜GPL-2.0**

[GitHub 官方仓库](https://github.com/mifi/lossless-cut)

**它解决什么问题？**

假设你录制了一段 40 分钟的视频，只想保留其中 3 分钟。

使用传统视频剪辑软件，导出时可能需要重新编码，既费时间，又可能损失画质。

LosslessCut 的核心思路是：**尽可能直接复制原视频的数据流，而不是重新编码。**

因此，它可以非常快速地完成视频和音频的裁剪、分割、合并等操作。

**最亮眼的地方：** 处理大型视频时尤其省时间。它适合整理课程录屏、游戏录像、相机视频，以及从长视频中截取需要的片段。

需要注意，快速无损裁剪通常受到关键帧位置限制，不一定能精确到任意一帧。项目在 2026 年 10 月 19 日仍发布了修复版本。

**使用门槛：** GitHub 提供免费的可执行版本；部分应用商店版本需要付费，用于支持开发者。

**隐私提醒：** 常规本地剪辑不需要上传视频，但重要素材建议保留原件，避免误操作。

**推荐指数：★★★★★**

如果你经常处理视频，这个工具值得收藏。

## ④ KeePassXC — 把所有密码放进自己的加密保险箱

**⭐ 约 29k｜Windows / macOS / Linux｜GPL 系列许可证**

[GitHub 官方仓库](https://github.com/keepassxreboot/keepassxc)

**它解决什么问题？**

网站越来越多，每个账号都设置不同密码很难记住。

但所有网站使用相同密码，一旦其中一个网站发生数据泄露，其他账号也可能受到影响。

KeePassXC 可以在本地创建一个加密密码数据库，统一管理不同网站的账号密码。

**最亮眼的地方：**

它不要求注册云端账号，密码数据库由你自己保存。

同时支持随机密码生成、浏览器自动填充、TOTP 验证码管理，以及硬件安全密钥等功能。

项目在 2026 年 3 月发布了 2.7.12 版本，9 月仍有代码更新。

**使用门槛：** 完全免费。初次使用需要创建数据库、设置主密码，浏览器自动填充需要安装官方扩展。

**隐私提醒：** 必须妥善保管主密码，并定期备份加密数据库。忘记主密码且没有其他解锁方式，可能永久失去访问权限。

**推荐指数：★★★★★**

适合重视隐私、希望自己控制密码数据的人。缺点是跨设备同步和备份需要自己管理。

## ⑤ FreeTube — 一个不需要登录账号的视频客户端

**⭐ 22.1k｜Windows / macOS / Linux｜AGPL-3.0**

[GitHub 官方仓库](https://github.com/FreeTubeApp/FreeTube)

今天的影音娱乐推荐。

**它解决什么问题？**

你想订阅一些科技、学习或娱乐频道，但又不希望每次打开视频平台，都被推荐算法带着不断刷下去。

FreeTube 是一个面向 [YouTube](https://www.youtube.com) 的第三方开源桌面客户端。

它允许用户：

- 不登录账号也能订阅频道。
- 在本地保存订阅、播放列表和观看历史。
- 将订阅划分成不同的 Profiles。
- 使用不同的视频获取方式，减少对官方网页的依赖。

**最亮眼的地方：** 可以把学习频道和娱乐频道分开管理，减少推荐内容的干扰。

不过，FreeTube 仍处于 Beta 阶段，视频播放功能可能因为上游平台调整而临时失效。项目在 2026 年仍持续更新播放兼容性。

**使用门槛：** 免费，安装即可使用，不需要自己部署服务器。

**隐私提醒：** 本地保存观看历史不代表完全匿名。视频服务仍可能看到你的 IP 地址和相关网络请求。

**推荐指数：★★★★☆**

适合经常观看国外科技频道、课程视频，又不想让推荐算法占据太多注意力的人。
