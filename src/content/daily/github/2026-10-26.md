## ① Anki — 让知识真正进入长期记忆

**⭐ 32.3k Stars｜Windows / macOS / Linux / Android / iOS｜AGPL-3.0-or-later**

[GitHub 官方仓库 · Anki](https://github.com/ankitects/anki)

### 它解决什么问题？

有没有这种情况：明明学过一个知识点，过了两周却忘得差不多了？

Anki 是一款基于**间隔重复（Spaced Repetition）**的记忆工具。

它不是简单地让你每天刷一遍所有知识，而是根据你的记忆情况，安排下一次复习的时间。

例如，你今天记住了一个概念，系统可能安排你几天后复习；如果你仍然记得，下一次复习间隔就可能进一步延长。

### 最亮眼的功能：FSRS 智能复习调度

Anki 支持 FSRS（Free Spaced Repetition Scheduler）算法，根据你的复习记录估计记忆状态，安排后续复习。

它还支持：

- LaTeX 数学公式、图片、音频和视频卡片。
- 完形填空式卡片（Cloze）。
- 自定义卡片模板。
- 插件扩展和跨设备同步。

**使用门槛：低～中。** 桌面版免费，Android 版 AnkiDroid 免费，官方 AnkiWeb 同步服务免费；官方 iOS 客户端 AnkiMobile 是付费应用。

**隐私提醒：** 本地使用不需要上传卡片，但启用 AnkiWeb 同步后，卡片内容会存储在同步服务上。涉及私人信息的卡片应谨慎处理。

**维护情况：** 2026 年 9 月 23 日发布 26.09.3。此前的 26.09 包含重要安全修复，建议使用较新版本。[^1]

**推荐指数：★★★★★**

尤其适合长期学习英语词汇、数学定义、专业术语，以及那些需要反复记忆的知识。

不过，Anki 更适合巩固已经理解的内容，不建议把尚未理解的知识直接做成卡片死记硬背。

## ② Loop Habit Tracker — 简洁、免费、没有广告的习惯追踪器

**⭐ 10.4k Stars｜Android｜GPL-3.0**

[GitHub 官方仓库 · Loop Habit Tracker](https://github.com/iSoron/uhabits)

### 它解决什么问题？

你可能想坚持每天阅读、锻炼、背单词或者早点睡觉，但经常做几天就忘了。

Loop Habit Tracker 可以帮你记录习惯完成情况，并通过图表展示长期变化。

它支持每日习惯，也支持每周完成三次、隔天执行等灵活计划。

### 最亮眼的功能：Habit Score

很多习惯软件只关注连续打卡天数。

一旦中断一天，连续记录就会归零。

Loop 的 Habit Score 则更关注长期表现：完成习惯会提高分数，偶尔中断会降低分数，但不会直接抹掉之前所有积累。

这比单纯追求连续打卡更合理。

另外，它支持桌面小组件、提醒，以及 CSV 和 SQLite 数据导出。

**使用门槛：极低。** 免费开源，无广告、无内购，不需要注册账号。

**隐私提醒：** 官方说明应用可以完全离线使用，不会主动向开发者上传习惯数据。不过，更换手机前最好导出备份。

**维护情况：** 2026 年 10 月 17 日发布 v2.3.2，修复了小组件、习惯编辑界面等问题。

**推荐指数：★★★★★**

适合想培养长期习惯，但不喜欢复杂任务管理软件的人。

我的建议是刚开始只追踪两三个习惯。习惯追踪器应该减少管理负担，而不是成为新的待办任务。

## ③ Deskflow — 一套鼠标键盘控制多台电脑

**⭐ 30.2k Stars｜Windows / macOS / Linux / FreeBSD｜GPL-2.0**

[GitHub 官方仓库 · Deskflow](https://github.com/deskflow/deskflow)

这是今天我最喜欢的项目。

### 它解决什么问题？

假设你有一台 Windows 台式机和一台 Linux 笔记本。

两台电脑各有自己的显示器、鼠标和键盘。

你想从一台电脑切换到另一台，就需要重新操作对应设备。

Deskflow 可以让它们共享一套鼠标和键盘。

### 最亮眼的功能：跨电脑无缝移动鼠标

例如：

你把 Windows 电脑放在左边，Linux 电脑放在右边。

只需要把鼠标移动到 Windows 屏幕右侧边缘，鼠标指针就能进入 Linux 电脑。

键盘输入也会跟着切换。

它还支持剪贴板共享，可以在不同电脑之间复制粘贴内容。

**与远程桌面的区别：**

Deskflow 不会把另一台电脑的画面传输过来，而是让你用同一套输入设备控制附近的多台电脑。

因此，它更适合桌面上同时摆放多台电脑的场景。

**使用门槛：中。** 免费开源，安装后需要配置设备连接、屏幕排列和系统权限。Windows 可能需要额外的 Visual C++ 运行库。

**隐私提醒：** Deskflow 默认启用 TLS 加密，但共享键盘、鼠标和剪贴板涉及敏感输入，建议只在可信局域网中连接自己的设备。

**维护情况：** 2026 年 10 月 1 日发布稳定版 v1.27.0，10 月 25 日仍有持续构建版本。[^2]

**推荐指数：★★★★★**

适合同时使用 Windows、Linux 或 macOS 的人。

如果你只有一台电脑，就没必要安装它；但如果有两台以上设备，它可能明显改善桌面工作体验。

## ④ Aves — 不只是相册，还是照片信息浏览器

**⭐ 5.5k Stars｜Android｜BSD-3-Clause**

[GitHub 官方仓库 · Aves](https://github.com/deckerst/aves)

今天的小众宝藏项目。

### 它解决什么问题？

手机自带相册通常侧重照片展示、分类和云端备份。

但如果你想深入查看照片信息，比如拍摄时间、相机参数、地理位置和图片格式，就不一定方便。

Aves 是一款面向 Android 的相册和媒体元数据浏览器。

它支持 JPEG、MP4、SVG、多页 TIFF 等格式，还能识别动态照片、全景图和 360° 视频。

### 最亮眼的功能：通过元数据探索照片

例如，你可以通过照片的地理位置、标签和相册进行查找。

对于喜欢拍照的人，Aves 不只是查看照片，还可以帮助整理和理解自己的媒体资料。

**使用门槛：低。** 免费开源，可以直接安装。项目提供不同发行版本，包括 Aves Libre。

**隐私提醒：** Aves 需要访问你授权的照片和视频。不同发行版本包含的服务集成有所区别，Aves Libre 不包含 Google 地图和可选的 Crashlytics 错误报告功能。

此外，照片 EXIF 信息可能包含拍摄位置，分享原图时需要注意是否暴露隐私。

**维护情况：** 2026 年 10 月 21 日发布 v1.15.8。

**推荐指数：★★★★☆**

适合 Android 摄影爱好者，以及希望更自由地管理本地照片的人。

社区中也有人把 Aves Libre 与 Fossify Gallery 进行比较。前者更偏重媒体格式和元数据探索，后者则更强调简单、可定制的日常相册体验。[^3]

## ⑤ Fossify File Manager — 没有广告的 Android 文件管理器

**⭐ 1.8k Stars｜Android｜GPL-3.0**

[GitHub 官方仓库 · Fossify File Manager](https://github.com/FossifyOrg/File-Manager)

今天第二个小众项目，Star 不算高，但实用性不错。

### 它解决什么问题？

很多 Android 文件管理器要么功能过于简单，要么加入大量广告、推荐内容和不必要的联网功能。

Fossify File Manager 是一款强调隐私、离线使用和可定制性的文件管理器。

它支持文件搜索、排序、压缩、收藏常用文件夹，以及查看存储空间使用情况。

### 最亮眼的功能：简单但不简陋

它支持 SD 卡和 USB 存储设备管理，也可以通过密码、图案或指纹锁保护应用及部分隐藏内容的访问。

同时不需要联网就能完成基本文件操作。

**使用门槛：极低。** 免费开源，安装即可使用。

**隐私提醒：** 文件管理器需要较广泛的存储访问权限，安装时应确认来源可信。应用锁也不等于文件内容已经经过加密，重要文件仍需要单独保护。

**维护情况：** 2026 年 10 月 24 日发布 v1.6.3，主要更新了翻译内容。

**推荐指数：★★★★☆**

适合希望摆脱广告、使用简单文件管理工具的 Android 用户。

如果你的系统自带文件管理器已经很好用，也不必为了开源而更换。
