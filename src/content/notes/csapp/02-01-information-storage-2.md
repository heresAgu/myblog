## 1. 布尔代数：对每一位分别运算

把 `0`、`1` 分别当作假、真，四种基本操作如下。对位向量运算时，**同一位置的位各自计算**，不发生进位。

| 运算 | C 位运算符 | 单个位何时为 `1` | 集合视角 |
| --- | --- | --- | --- |
| 非 | `~` | 原位为 `0` | 补集 |
| 与 | `&` | 两个位都为 `1` | 交集 |
| 或 | `\|` | 至少一个位为 `1` | 并集 |
| 异或 | `^` | 两个位不同 | 对称差 |

以 **4 位**位向量 `a=0110`、`b=1100` 为例：

```text
a & b  = 0100       a | b = 1110
a ^ b  = 1010       ~b    = 0011   （只取 4 位）
```

每一位也可对应一个集合元素：位为 `1` 表示元素存在。于是 `&`、`|`、`~` 分别对应集合交、并、补。异或满足 `x ^ x = 0`、`x ^ 0 = x`；这些性质可以用来推导位模式。

## 2. C 位运算：直接改某些位

位运算常与**掩码**搭配。下面以 `uint32_t x = 0x87654321u` 为例：

| 目标 | 表达式 | 结果 |
| --- | --- | --- |
| 只保留最低 8 位 | `x & 0xFFu` | `0x21` |
| 把最低 8 位都置 `1` | `x \| 0xFFu` | `0x876543FF` |
| 把最低 8 位都清 `0` | `x & ~0xFFu` | `0x87654300` |
| 翻转最低 8 位 | `x ^ 0xFFu` | `0x876543DE` |

掩码只说明要操作哪些**位位置**；`~` 的结果要结合参与运算的整数宽度和 C 的整数提升来理解。例如书里的 `~0x41`，若只讨论 8 位结果是 `0xBE`，但实际 C 表达式 `~0x41` 通常以 `int` 宽度计算，不能直接把整项写成 `0xBE`。

书中用“三次异或”演示原地交换，但若两个指针指向**同一位置**，第一次 `*x = *x ^ *y` 就把值清成 `0`；实际代码用普通临时变量交换更清楚。

## 3. 位运算与逻辑运算不能混用

![按位运算、逻辑运算及移位的区别](images/信息存储-位运算与移位.png)

| 对比 | 位运算 `&`、`\|`、`~`、`^` | 逻辑运算 `&&`、`\|\|`、`!` |
| --- | --- | --- |
| 处理方式 | 按每一位计算 | 先把 `0` 看成假、非零看成真 |
| 结果 | 位模式 | `0` 或 `1` |
| 求值 | 二元位运算会计算两边 | `&&`、`\|\|` 有短路行为 |

例如 `(0x69 & 0x55) == 0x41`，而 `(0x69 && 0x55) == 1`；`!0x41 == 0`。位运算与比较混用时应加括号，避免运算符优先级造成误读。

短路可用于保护访问：`p != NULL && *p == 7` 在 `p` 为 `NULL` 时不会解引用 `p`。把 `&&` 换成 `&` 就没有这种保护。

## 4. 左移与右移

对于固定宽度的位向量，`x << k` 把位向左移动 `k` 位，右侧补 `0`，越过宽度的高位丢弃。`x >> k` 向右移动；**逻辑右移**左侧补 `0`，**算术右移**左侧复制原最高位。

```text
8 位示意：x = 1001 0110
x << 2             = 0101 1000   （丢弃最左边两位）
x >> 2，逻辑右移   = 0010 0101
x >> 2，算术右移   = 1110 0101
```

在 C 中，无符号整数右移补 `0`；对**负的有符号整数**右移，本书所用的 C 语境下结果依赖实现，常见机器使用算术右移。上面的 8 位图只是位向量示意：`uint8_t` 等窄类型在 C 表达式中还可能先发生整数提升。

**边界要记住：**移位数不能为负，也不能大于或等于提升后左操作数的位宽，否则行为未定义。若需要明确的位模式，先选定无符号定宽类型；不要依赖负数左移、有符号数左移溢出或“超宽移位会自动取模”。

## 一页复习与自测

- `&` 清位或取字段；`|` 置位；`^` 翻转位；`~` 按当前运算宽度逐位取反。
- `&&` 和 `||` 表达真假并可能短路；`&` 和 `|` 处理位模式。
- 判断端序看**字节顺序**；判断移位看**位方向、补位规则、操作数类型与宽度**。

**试一试：**对 `uint32_t x = 0x87654321u`，写出保留最低 16 位、清除最低 8 位的表达式。`p == NULL` 时，`p != NULL && *p == 7` 是否会访问 `*p`？

<details><summary>参考答案</summary>

`x & 0xFFFFu` 得到 `0x4321`；`x & ~0xFFu` 得到 `0x87654300`。第二个表达式会短路，不访问 `*p`。

</details>
